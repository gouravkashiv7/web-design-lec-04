# Lab and Homework: College Admission Form

**Lecture 04** · HTML only · Save it as `admission.html`

## Lab (in class)

Build a proper admission form. It must have:

- [ ] Every field has a label linked with `for` / `id`
- [ ] The right `type` for email, phone and date of birth
- [ ] A `select` for the course, a `textarea` for the address
- [ ] `required` on every field that must be filled
- [ ] A consent checkbox and a real submit `button`
- [ ] Fill it in with the keyboard only, start to finish

The first field in `starter/admission.html` is done for you. Copy its pattern.

## Homework (due before Lecture 05)

Update every page of your `college-site/`:

- [ ] `header`, `nav`, `main` and `footer` on every page
- [ ] Alt text on every image (`alt=""` if decorative)
- [ ] Finish `admission.html` and link it from the contact page
- [ ] Every field has a label, the right type, `required`
- [ ] Walk through each page with the keyboard only
- [ ] Validate every page at [validator.w3.org](https://validator.w3.org/#validate_by_upload)

## Submit

`admission.html` · keyboard-only walkthrough notes (what worked, what didn't) · three semantic changes you made and why each one helps
